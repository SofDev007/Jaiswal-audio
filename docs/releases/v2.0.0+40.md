JARX 2.0.0 (build 40)

Clearer update notices.

What's new
- Update notices show the build you have and the latest build, each with the date it came out. Builds you skipped are listed underneath, and nothing is repeated.
- The bell shows only the latest update. Old notices for earlier builds are gone, and once you've updated the bell's count disappears.
- Settings › Check for updates now downloads and installs inside JARX, like the bell. It used to open a website in the browser.
- Play video is only for songs from the YouTube Video plugin (search with the ytvideo source).
