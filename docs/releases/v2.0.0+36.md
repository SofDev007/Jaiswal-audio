JARX 2.0.0 (build 36)

Updating is now one tap inside JARX.

What's new
- In-app updates: tap Update and JARX downloads the new version itself, with a progress bar, then opens Android's install screen. The first time, Android asks you to allow JARX to install apps.
- "What's new" lists every version you skipped, not just the newest one.
- Safer server: limits against misuse, stronger protection for the admin page, and banned accounts can still delete themselves.
- The app is now signed with a password-protected key (same key as before, so it updates over your current JARX with nothing lost).
